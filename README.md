# SoulScriptly

SoulScriptly is a full-stack personal notes and private diary application.

Users can:

- Create and manage notes
- Write private diary entries
- Protect their diary with an additional lock
- Upload images and videos
- Personalize their diary with their own handwriting
- Search their diary entries

## Tech Stack

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma
